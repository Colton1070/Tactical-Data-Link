https://tdl.blufor.info ("BLUFOR Service") for additional functionality,
including:

  * Image processing, quantization, and display capabilities
  * Map metadata, layers, and user-placed marker storage and sync
  * Real-time position and marker data synced between game servers and clients
  * Server registration and management (including invitation codes and
    multiple API keys per server)
  * Cloud-based data storage, transmission, and short-lived messaging
  * API access for server integration

--------------------------------------------------------------------------------
                         DATA PROCESSING NOTICE
--------------------------------------------------------------------------------

When using external service features, the following data may be processed:

  * Image files uploaded for processing (including derivatives submitted to
    third-party moderation APIs)
  * Maps, layers, and user-placed markers
  * Marker and position data synced between game servers and clients
  * Server metadata (name, status, player counts, network counts, device
    counts) and network/device state snapshots
  * Command queue items and execution history
  * Event logs and activity data
  * Account, session, and server-integration state
  * Short-lived messaging or delivery payloads (which may auto-expire on a
    schedule)

Image and map asset data may be stored in Cloudflare R2 (or compatible object
storage). Application data is stored in databases and caches (such as MongoDB
and Redis) operated by us or our hosting providers. All data in transit uses
encrypted HTTPS connections. For full details on subprocessors, retention, and
security, see the Terms of Service and Privacy Policy.
